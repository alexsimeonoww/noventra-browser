Streaming setup

Allowing protected content below does not install Widevine. Some streaming services also need this component from Google. Its downloads are optional and off by default.

  1. Install or manage Widevine and allow its downloads. Wait for an installed version to appear.
  2. After installation, quit Noventra completely, then reopen the browser.
  3. Allow protected content below, then reload your streaming page.

Some services require an approved browser. Installing Widevine does not guarantee that every streaming service supports Noventra.
